# OOP Mini Project Viva Questions

1. **What is OOP?** Object-Oriented Programming is a programming approach based on classes and objects.
2. **What is a class?** A blueprint defining data members and member functions.
3. **What is an object?** An instance of a class.
4. **What is encapsulation?** Combining data and functions and controlling access to data.
5. **What is inheritance?** A derived class acquiring features of a base class.
6. **What is polymorphism?** One interface showing different behavior.
7. **What is abstraction?** Hiding implementation details and showing essential features.
8. **What is an abstract class?** A class with at least one pure virtual function.
9. **Why is displayRole() virtual?** To select the correct overridden function at runtime.
10. **What is function overloading?** Same function name with different parameter lists.
11. **Why is vector used?** It stores a dynamically sized collection of objects.
12. **What is file handling?** Reading from and writing data to files.
13. **Why save records in files?** Data remains available after the program closes.
14. **What does const after a member function mean?** The function does not modify the object's data members.
15. **What is a constructor?** A special function that initializes an object.
